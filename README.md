# UniFiles YouTube Music

Browse and play music from YouTube Music in UniFiles.

## Install

1. In UniFiles, open **Media → Media sources → + → Install plugin**.
2. Paste this manifest URL:

   ```text
   https://github.com/monokaijs/unifiles-youtube-music/releases/latest/download/manifest.json
   ```

3. Tap **Install**, then return to **Media** and select the new source tab.

For regular YouTube, use [unifiles-youtube](https://github.com/monokaijs/unifiles-youtube). You can install both sources together.
